# 六种FPV运镜：素材先行示例

## 输入与承诺

目标：教观众用具体起点、路径、朝向和结束状态描述运镜；六种动作是DIVE、PROXIMITY、ORBIT、GAP、TRACKING、ROLL。视频16:9，生成片段计划每段10秒，用户真人首尾，中间真实口播。完整中文优化提示词在画面，中英文可替换模板作为评论区资料。

## 实际路径与结果

六段生成→动作验收→ROLL局部重试→依据画面写录制稿→用户交84.760秒实录及SRT→章节页/全文卡片包装→视觉比较与审阅→3:4、4:3封面→标题正文。

原素材约10.125秒；第一版ROLL侧倾回摆，未完成完整翻滚，标不合格。重试出现倒置后继续恢复水平，初步接受；没有严格证明各阶段按提示词计划秒数发生。生成场景属于相近工业园，不能宣称完全同一建筑布局。

## 可复用示例

prompts.json保留提交原文与屏幕优化版；优化版没有重新生成。comment-prompts.md是通用可替换中英文模板，不是工业园示范全文的逐句译文，使用时要明确区分。

storyboard.csv记录实际章节时间。示例不附原片，不能直接渲染；需要自己生成/替换素材并提交真实音频。原制作只有SRT片段时间，逐词对齐未完成，不应当作已完整词级验证案例。

## 重跑方法

1. 用素材先行入口，配置自己的作者身份和工具。
2. 生成六个独立动作；未授权付费重试时先停在失败报告与重试方案。
3. 全片动作验收后写稿，再录制。
4. 用自己的真实SRT建立章节，不复制示例时间冒充自己的录音。
5. 检查动作事件、全文卡片和音频后交审阅；认可后交封面、文案和评论资料。

## 脱敏范围

不含真人照片、录音、视频、生成服务任务ID、密钥、用户名、本地绝对路径或字体文件。无需访问原作者的环境。
