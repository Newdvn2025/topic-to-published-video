**面向AI科普与知识分享，用成本可控的方式快速制作小红书视频。**

先由创作者选择话题、自行调研并确定大纲，再把大纲交给AI，调用本技能。AI按步骤准备口播、生成演示配片、整理录制素材、设计包装并交付视频、封面和发布文案。创作者负责内容判断、录制或数字人制作，以及关键阶段确认。

本技能附带AutoDL调用脚本和工具技能安装向导，推荐AutoDL生成B-roll、HyperFrames完成包装，Remotion和ChatCut可选。成本与耗时取决于素材数量、生成重试和所选服务，不承诺固定价格或一键免确认成片。

## 开始前，你准备什么

1. 选一个具体话题，明确目标观众和想解决的问题。
2. 自行调研，整理关键知识点、可信来源与必要的演示案例。
3. 确定大纲：开头痛点、分段讲解、总结和行动提示。
4. 把大纲、参考资料和已有素材交给AI，说明期望画幅、出镜方式或风格。没指定时视频默认16:9，封面另做3:4，可追加4:3。

建议这样发给AI：

> 用 $topic-to-published-video 做一期小红书AI科普视频。我已完成调研，下面是大纲和参考资料。请先确认内容框架，再按SOP推进口播、B-roll、录制指引、包装、封面与发布文案。生成付费素材前确认具体计划。

只有话题、还没有大纲也能启动：AI协助整理框架，对需要验证的事实补充核查；已有完整大纲时不要求重新选题，尊重用户结构，仅指出事实缺口或画面难以支持的承诺。

## 完整SOP

| 步骤 | AI负责什么、交付什么 | 用户负责什么、确认什么 |
|---|---|---|
| 0 初始化 | 检查已有环境；推荐AutoDL+HyperFrames，提供全部安装和自选；引导Key配置与工具连接 | 选择组合，在本地配置Key；已有配置直接复用 |
| 1 确认框架 | 根据调研大纲整理痛点、结果承诺、章节结构、案例与演示思路 | 确认框架符合内容意图 |
| 2 准备内容 | 同时交口播草稿、B-roll镜头清单、完整生成提示词、预计节奏与生成计划 | 确认讲法、配片与本次生成范围 |
| 3 生成与验收B-roll | 调用AutoDL等已选工具，下载素材，检查实际动作；不合格只处理对应片段 | 必要时确认追加重试预算 |
| 4 锁最终录制稿 | 按合格素材修订可直接录制的口播、停顿与出镜清单；时长仍为预计 | 确认录制稿，选择自行录制或数字人 |
| 5 获取口播 | 给录制指引或HeyGen地址与分段清单；B-roll覆盖段可仅保留音频、画面留白 | 自行录制或制作数字人，提交视频/音频与已有字幕 |
| 6 整理A-roll | 多段、重复录制先用ChatCut或所选编辑器剪成完整口播主线，再生成/对齐字幕 | 确认完整口播；此时锁定真实文字与时间 |
| 7 确定包装 | 逐段规划真人与B-roll衔接、章节页、解释图、提示词卡片、总结和片尾；输出视觉方向 | 确认风格与信息展示方式 |
| 8 九宫格预览 | 按实际内容、素材和已选风格生成关键画面的九宫格 | 确认布局与信息层级 |
| 9 动态制作 | 用HyperFrames或Remotion完成画面、字幕、原声/选定旁白、音乐及渲染；交动态审阅版 | 看片并按时间点反馈，通过后锁定最终视频 |
| 10 发布包 | 交3:4/所需4:3封面、标题、正文、标签与承诺的评论区资料 | 确认封面文案，自行发布；代发布需另行授权 |

**两个关键顺序：先验收B-roll，再交最终录制稿；先剪定A-roll，再锁字幕与包装。**

生成素材的时长只用于预估，最终成片以剪定口播的真实时间为准。九宫格用于看风格与布局，不能替代动态审阅。用户明确说“可以，继续”后，从下一阶段推进，不重复已经确认的步骤。已有B-roll或实录的用户直接进入相应阶段。

数字人仅在需要出镜的部分生成，可减少不必要的渲染；配片覆盖段保留旁白，空白只作交接占位。事后删掉数字人画面不会自动减少已产生的费用，实际计费以所用服务为准。

## 安装到 Codex

仓库：[Newdvn2025/topic-to-published-video](https://github.com/Newdvn2025/topic-to-published-video)

使用skills安装器：

```bash
npx skills add Newdvn2025/topic-to-published-video --skill topic-to-published-video --agent codex --global
```

安装后在Codex调用`$topic-to-published-video`，说“初始化”，再选择工具组合。首次安装可能需要重新加载宿主技能。

也可以手动安装：

下载本目录，把包含SKILL.md的整个文件夹放到你的Codex技能目录，例如`~/.codex/skills/topic-to-published-video`。如已有同名技能，先备份，再选择替换或在单独环境试用。安装只需本目录，不依赖原作者的私人技能。

具体技能目录由你的代理环境决定；其他支持SKILL.md的代理可以按其安装方式使用。重新加载技能后，以`$topic-to-published-video`调用。

## 首次初始化

AI先询问推荐组合（AutoDL+HyperFrames）、全部安装（追加Remotion+ChatCut）或自选。也可在本地终端运行：

```bash
python3 scripts/setup.py --workspace ./my-video
```

配置环境变量AUTODL_ART_TOKEN，或运行python3 scripts/setup.py key隐藏输入，保存到用户配置目录的topic-to-published-video/autodl.env。无需把Key发给AI。[完整初始化指南](references/initialization.md)说明安装范围、Key位置和应用连接步骤。

## 快速开始

复制config/creator.example.json到项目目录的creator.json，填写作者称呼和片尾。也可以在对话中指定，AI应落盘。

三种示例请求：

- “用topic-to-published-video做一期AI教学视频，主题是六种FPV运镜，先给定位和录制稿。”
- “我已有六段演示视频，先验收动作，再按实际画面写口播。使用16:9，生成重试前告知成本。”
- “我已有出镜视频和SRT，保留原声，给中间配B-roll并制作章节页，先交审阅版。”

确认某阶段后说“可以，继续”，工作流应从最新状态接着做；说“这期已录好”时应进入实录路径，而不是要求重新生成脚本。

## 依赖与降级

| 能力 | 所需条件 | 不可用时 |
|---|---|---|
| 定位、脚本、提示词、分镜、发布文案 | 可读写项目文件的语言模型代理 | 无需生成服务 |
| 普通字幕 | 用户SRT，或可用转写服务 | 等待真实音频/SRT，不伪造时间 |
| 逐词动效 | 可靠词级转写/音频对齐工具 | 使用片段字幕，明确精度 |
| 图像/视频生成 | 用户提供素材，或已配置生成服务 | 输出生成计划与提示词 |
| 剪辑与渲染 | 可用编辑器或引擎及其运行环境 | 输出时间轴和素材包 |
| 发布 | 明确授权和可用发布接口 | 交可复制的发布包 |

AutoDL与HyperFrames是推荐基础组合，Remotion、ChatCut可选，也可使用已有素材。AutoDL调用脚本已打包，用户配置自己的Key；安装技能不会自动提交付费任务。ChatCut还需安装/打开应用并完成登录。详细路由见references/tools.md。

## 项目输出

模板在templates/，唯一真源与状态约定见references/artifacts.md。示例在examples/fpv-six-moves/，包含真实生产经验、脱敏分镜及提示词，未包含真人素材、生成视频和服务账号。

默认视频16:9，主封面3:4，可追加4:3；用户要求优先。作者身份和片尾为空时，不写入任何人的姓名。
