# 能力检查与可替换工具

首次使用先按[初始化指南](initialization.md)询问组合。AutoDL调用已包含；AutoDL和HyperFrames推荐基础安装，Remotion、ChatCut可选。

先使用宿主可用的文件、转写、生成、编辑和渲染能力；只有实际选择工具时才加载该工具技能或官方说明。此技能不依赖原作者的私人环境；所选第三方技能从官方仓库安装。

| 能力 | 可选实现 | 无实现时 |
|---|---|---|
| 转写/对齐 | 宿主转写、可配置本地或远程对齐工具 | 用用户SRT；缺音频则等待，不估时间 |
| 视频素材 | 用户片段、AutoDL、其他生成服务 | 输出镜头提示词和任务计划 |
| 图像封面 | 宿主图像生成、可用设计工具 | 输出文案、布局与参考素材包 |
| 剪辑 | HyperFrames、Remotion、ChatCut、用户编辑器 | 输出有真实时间的分镜和剪辑交接 |
| 技术检查 | ffprobe/ffmpeg、编辑器元数据 | 记录可用检查和未覆盖项 |
| 音乐 | 用户授权素材、原创或可用服务 | 报告缺口，不擅加来源不明音乐 |

AutoDL等生成工具需要相应账号、网络和预算；HyperFrames/Remotion需要各自运行环境；宿主生成工具按其接口使用。不要复制某工具旧参数到另一服务，不把图像生成技能的存在当作视频生成能力。

如专业技能可用，可用其精细规则，但本工作流保留独立的脚本、分镜、验收和交付能力。选择引擎及切换原因写入状态。
